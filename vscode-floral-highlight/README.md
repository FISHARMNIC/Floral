# Floral Language Syntax Highlighting

A VSCode extension for syntax highlighting of the Floral programming language.

## Features

- Syntax highlighting for `.bud` files
- Smart indentation for control structures
- Bracket matching and comment support (`//` and `/* */`)
- Highlighted tokens for keywords, types, functions, strings, numbers, and operators
- `$Type` shared variable prefix highlighted distinctly

## Installation

Install the `.vsix` file via the Extensions sidebar in VSCode (Extensions > `...` > Install from VSIX).

## Development

Edit `syntaxes/daisy.tmLanguage.json` to modify syntax rules, then reload the extension window with `Ctrl+Shift+P`.
